# Lume - AI人生规划陪伴者

一款专为18-25岁青年群体打造的AI人生规划陪伴助手。

## 项目简介

Lume（璐觅）致力于解决当代青年在学业、职业选择和人生方向上的迷茫问题，通过全面测评+深度背景分析+人生路径模拟+温暖陪伴的方式，为用户提供个性化的成长路径规划和持续的情感支持。

## 核心功能

- **人生路径模拟**：基于用户当前情况，模拟展示未来五年、十年的人生轨迹
- **个性化目标规划**：生成年度、月度、每日的详细行动计划
- **智能目标推荐**：根据用户个人情况智能推荐适合的发展方向
- **每日打卡互动**：通过每日任务打卡机制，帮助用户养成良好习惯
- **情感陪伴支持**：温暖的AI伙伴，给予鼓励和理解

## 技术栈

- **框架**: UniApp (Vue 3)
- **语言**: TypeScript / JavaScript
- **样式**: SCSS
- **构建工具**: Vite

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
# H5开发
npm run dev:h5

# 微信小程序开发
npm run dev:mp-weixin
```

### 构建生产版本

```bash
# H5构建
npm run build:h5

# 微信小程序构建
npm run build:mp-weixin
```

## 设计理念

- **温暖贴心**：采用粉色渐变为主色调，营造温暖、亲切的视觉感受
- **简洁易用**：清晰的导航结构，让用户轻松找到所需功能
- **情感陪伴**：通过温柔的语言和动画效果，让用户感受到被关怀
